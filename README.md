# SMKAMi – Pelancar

Halaman kecil yang dihoskan di GitHub Pages. Halaman ini memberi logo SMKAMi sebagai ikon apabila guru menekan **Add to Home Screen**, kemudian terus membuka aplikasi guru (Google Apps Script).

- Pautan aplikasi ditetapkan dalam `index.html` (pemboleh ubah `APLIKASI`).
- Ikon: `apple-touch-icon.png` (iPhone/iPad), `ikon-192.png` dan `ikon-512.png` (Android).
